# Web Rubik's Cube

![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white)
![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=for-the-badge&logo=javascript&logoColor=%23F7DF1E)

An interactive, web-based Rubik's Cube simulation.

## Overview
This project aims to provide a playable 3D Rubik's Cube directly in the browser.

## Usage
Simply open the HTML file in any modern web browser to interact with the cube.
