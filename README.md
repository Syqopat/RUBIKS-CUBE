**RUBIKS-CUBE** is a 3D browser-based interactive Rubik's Cube solver and scrambler application powered by WebGL and Three.js.

---

## 📌 Project Status

- **Status:** 🟢 **Working / Stable**
- **CI/CD:** Automated GitHub Actions validation check enabled.

---

## 🚀 Key Features

- **3D Render Engine:** Real-time animated rotation of a 3x3x3 Rubik's Cube with Three.js.
- **Scramble & Solve:** Visualizes move step sequences and scramble actions.
- **User Controls:** Mouse and touch controls with 360-degree orbit camera view.

---

## 🛠️ Usage

No installation required. Open `rubiks-cube.html` directly in any web browser.
